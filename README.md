Summarist

Summarist is a platform designed for busy individuals, book lovers, and even those who barely have time to read. It allows users to extract the core ideas from the best books in just a few minutes. Whether you prefer to read or listen via Briefcasts, Summarist provides concise and accurate summaries to help you expand your learning, establish better reading habits, and achieve your personal growth goals. 

🚀 Live Demo

Check out the live project here: https://summarist-lemon.vercel.app

🛠️ Tech Stack

* Frontend: React, Next.js, Vue.js
* Backend: Node.js, Express, Firebase
* Database: MongoDB, PostgreSQL
* Styling: Tailwind CSS, Styled Components
* Hosting/Deployment: Vercel
